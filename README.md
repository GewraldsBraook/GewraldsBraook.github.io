# Gewralds Braook - Portfolio

Personal portfolio for a Backend .NET Engineer focused on aviation technology, distributed systems, and production reliability.

## Local preview

The site is buildless and has no package dependencies. Serve the repository root with any static HTTP server, for example:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Structure

- `index.html` - semantic content, metadata, and inline architecture illustration
- `styles.css` - responsive layout, themes, and motion-safe animations
- `app.js` - theme preference, scroll state, navigation state, and reveal behavior
- `favicon.svg` - local site icon

GitHub Pages publishes the `main` branch automatically.
